.. py:function:: lip_peptide_perturbation_scores(lip_pept: pandas.DataFrame, protein_solvent_accessibility_scores: pandas.Series, fold_change_column_name: str, protein_column_name: str = 'Protein') -> pandas.Series

   Calculates the LiP perturbation score from Sarkar et al. 2025
   (https://doi.org/10.1021/acs.jproteome.5c00400) for each peptide. This is
   calculated as the log2 fold change in peptide intensity multiplied by the
   solvent accessibility score for the protein. The solvent accessibility score
   is the ratio of the number of semi- or non-tryptic peptides in the double-digested
   samples to the number of fully tryptic peptides in the trypsin-only samples. In
   Sarkar et al. 2025, a protein perturbation score is calculated as the sum of
   the perturbation scores of all tryptic peptides mapping to a protein. Here, we
   calculate it at the per-peptide level. The resulting scores can be aggregated
   as needed.

   :param lip_pept: The double-digested peptide data frame with
                    log2 fold changes calculated.
   :type lip_pept: pd.DataFrame
   :param protein_solvent_accessibility_scores: The solvent accessibility scores for each protein.
   :type protein_solvent_accessibility_scores: pd.Series
   :param protein_column_name: The name of the column containing the protein IDs. Must be the same in both data frames.
   :type protein_column_name: str
   :param fold_change_column_name: The name of the column containing the log2 fold change values for the peptides. Only required in the `lip_pept` data frame.
   :type fold_change_column_name: str

   :returns: A series containing the LiP perturbation score for each peptide, indexed by the same index as `lip_pept`.
   :rtype: pd.Series
